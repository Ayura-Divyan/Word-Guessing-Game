#🕹 Word Guessing Game
---
A simple command-line word guessing game inspired by classic Pokémon titles!
Your task is to guess the hidden word — all possible answers are names of Generation 2 & Generation 3 Pokémon games.

**🎮 Gameplay**
The game randomly picks one of the following titles:
ruby, sapphire, emerald
diamond, platinum
heartgold, soulsilver

You’ll guess letters one at a time until you find the word (or run out of tries).
